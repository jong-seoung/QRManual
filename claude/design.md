# design — UI 스코프

지금 적용할 디자인 범위만 남긴다. 이 외(토큰 구조 표, 컴포넌트 라이브러리 후보, 레이아웃 패턴, 접근성 체크리스트, 정적 자산 규칙 등) 과거 항목은 모두 레거시로 간주하고 보류.

> 디자인 토큰 값의 출처는 **노션 기반 `DESIGN.md`** (루트 `DESIGN.md`). `npx getdesign@latest add notion --force`로 갱신. `DESIGN.md`가 라이트/다크 색상·타이포·둥글기·스페이싱 등 구체값의 단일 소스다.

## 1. 적용 범위

1. **반응형** — 데스크탑(`lg` 1024px+) 폭 안에서 가변 폭에 안정적으로 동작하면 충분. 모바일·태블릿 전용 최적화는 별도 결정 전까지 도입하지 않는다.
2. **다크·라이트 모드** — 처음부터 light/dark 토큰을 동시에 정의. `globals.css`의 `:root` / `.dark`에서 토큰 오버라이드, 컴포넌트는 토큰만 참조. 두 세트가 갖춰지지 않은 색상은 도입 금지.
3. **다국어** — 한·영 동시 지원. 텍스트는 `next-intl` 메시지로 추출, 영어 길이(약 1.2~1.5배)에서도 레이아웃이 깨지지 않게 컴포넌트 폭을 결정.

## 2. 검증

새 페이지/컴포넌트는 다음 조합에서 깨지지 않아야 머지 가능:

- 1280px / 1024px 두 데스크탑 폭
- 라이트 / 다크 두 테마
- `ko` / `en` 두 로케일
